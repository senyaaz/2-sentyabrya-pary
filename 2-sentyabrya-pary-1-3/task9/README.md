1. Название и описание задачи
Мини-графический редактор — это консольная программа на Python, демонстрирующая основные принципы объектно-ориентированного программирования (ООП).

Программа позволяет:
Создавать геометрические фигуры (круги и квадраты) с заданными координатами и размерами
Вычислять площадь каждой фигуры
Подсчитывать общую площадь всех созданных фигур
Проект создан в учебных целях для наглядной демонстрации трех ключевых концепций ООП: инкапсуляции, наследования и полиморфизма.

2. Архитектура проекта
Реализация трех концепций ООП:
2.1 Инкапсуляция
Скрытые данные: координаты __x и __y в классе Figure объявлены приватными (с двумя подчеркиваниями)

Публичные методы:
get_coords() — возвращает кортеж координат
set_coords(x, y) — изменяет координаты
Это защищает данные от прямого изменения и позволяет контролировать доступ к ним

2.2 Наследование
Базовый класс: Figure
Дочерние классы: Circle и Square

Дочерние классы наследуют:
Конструктор через super().__init__(x, y)
Методы get_coords() и set_coords()

Каждый дочерний класс добавляет свои уникальные атрибуты:
Circle: радиус r
Square: сторона side

2.3 Полиморфизм
Оба дочерних класса переопределяют метод calculate_area()
В главной программе метод вызывается единообразно для всех фигур:

for f in figures:
    total += f.calculate_area()

Метод работает по-разному в зависимости от типа фигуры:
Для круга: 3.14 * r * r
Для квадрата: side * side

3. Пример использования
# Создание фигур
circle = Circle(0, 0, 5)      # Круг с центром (0,0) и радиусом 5
square = Square(10, 10, 4)    # Квадрат с координатами (10,10) и стороной 4

# Получение координат
x, y = circle.get_coords()
print(f"Координаты круга: ({x}, {y})")

# Изменение координат
circle.set_coords(3, 5)

# Вычисление площади
print(f"Площадь круга: {circle.calculate_area():.2f}")
print(f"Площадь квадрата: {square.calculate_area():.2f}")

# Список фигур и подсчет общей площади
figures = [circle, square, Circle(3, 5, 2.5)]
total = sum(f.calculate_area() for f in figures)
print(f"Общая площадь: {total:.2f}")

4. Результат работы
При запуске программы создается 5 фигур (3 круга и 2 квадрата) с разными параметрами, после чего вычисляется и выводится их общая площадь.
Общая площадь: 182.28
