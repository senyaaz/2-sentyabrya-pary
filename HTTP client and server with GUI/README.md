# HTTP-клиент и сервер с графическим интерфейсом на Python

## 1. Описание проекта

Проект представляет собой настольное приложение на Python с графическим интерфейсом Tkinter. Приложение включает HTTP-клиент для отправки запросов и HTTP-сервер для обработки входящих соединений.

Клиент и сервер работают в рамках одного приложения. Сервер поддерживает запуск и остановку, а журналирование помогает отслеживать его работу.

## 2. Основные возможности

- Отправка HTTP-запросов GET и POST.
- Разбор URL, HTTP-запросов и ответов.
- Обработка статуса, заголовков и тела ответа.
- Поддержка HTTPS на стороне клиента.
- Обработка ответов с `Content-Length` и `Transfer-Encoding: chunked`.
- Запуск и остановка локального HTTP-сервера.
- Маршруты `/`, `/echo`, `/time`, `/headers` и `/status/{code}`.
- Ответ `404 Not Found` для неизвестных маршрутов.
- Ведение журнала работы приложения.
- Автоматические тесты компонентов проекта.

## 3. Требования

- Python 3.10 или новее.
- Tkinter.
- pytest для запуска тестов.

## 4. Структура проекта

- `src/http/` — модели HTTP, разбор URL, парсер и сериализатор.
- `src/net/` — сетевые соединения и TCP-клиент.
- `src/client/` — HTTP-клиент.
- `src/server/` — HTTP-сервер, маршрутизатор и обработчики.
- `src/gui/` — графический интерфейс.
- `src/main.py` — точка входа приложения.
- `src/logging_config.py` — настройка логирования.
- `tests/` — автоматические тесты.
- `run_server.py` — отдельный запуск сервера для ручной проверки.
- `app.log` — журнал работы приложения.

## 5. Запуск приложения

Открой терминал в корневой папке проекта и выполни:

python -m src.main

После запуска откроется графический интерфейс с вкладками клиента и сервера.

## 6. Примеры использования

### 6.1. Запуск сервера

Во вкладке «Сервер» укажи порт `8080` и нажми «Запустить».

Сервер будет доступен по адресу:

`http://localhost:8080/`

### 6.2. Проверка сервера через браузер

После запуска сервера открой браузер и введи адрес:

`http://localhost:8080/`

Браузер отправит GET-запрос к серверу, а на странице отобразится ответ главного маршрута — например, HTML-текст `<h1>Hello</h1>`.

Для проверки других маршрутов можно открыть следующие адреса:

- `http://localhost:8080/time` — получение текущего времени.
- `http://localhost:8080/headers` — просмотр заголовков запроса.
- `http://localhost:8080/nonexistent` — проверка ответа `404 Not Found`.

**Важно:** перед открытием адресов сервер должен быть запущен. Браузер подходит для проверки GET-запросов. Для проверки POST-запроса к `/echo` используй вкладку «Клиент» приложения или команду `curl` из терминала.

### 6.3. GET-запрос к главной странице

Во вкладке «Клиент» укажи URL:

`http://localhost:8080/`

Выбери метод `GET` и нажми «Отправить».

Ожидаемый результат: HTTP-ответ со статусом `200 OK`.

Также запрос можно выполнить из терминала:

curl http://localhost:8080/

### 6.4. POST-запрос к маршруту `/echo`

Выбери метод `POST`, укажи URL:

`http://localhost:8080/echo`

В теле запроса напиши `hello` и отправь запрос.

Пример проверки через терминал:

curl -X POST -d "hello" http://localhost:8080/echo

Ожидаемый результат: сервер возвращает переданное тело запроса.

### 6.5. Проверка ошибки 404

Выполни GET-запрос к неизвестному маршруту:

curl http://localhost:8080/none

Ожидаемый результат: ответ `404 Not Found`.

### 6.6. Проверка маршрута времени

Выполни запрос:

curl http://localhost:8080/time

Ожидаемый результат: HTTP-ответ с текущим временем в формате JSON.

### 6.7. Проверка маршрута `/headers`

Выполни запрос:

curl http://localhost:8080/headers

Ожидаемый результат: ответ с заголовками полученного HTTP-запроса в формате JSON.

## 7. Запуск тестов

Из корневой папки проекта выполни:

python -m pytest tests/ -v

Команда запускает автоматические тесты URL, парсера, сериализатора и других компонентов, включённых в набор тестов проекта.

## 8. Логирование

Сообщения о работе приложения записываются в файл `app.log`. Также сообщения выводятся в консоль и, для серверных событий, могут отображаться в графическом интерфейсе.

## 9. Остановка сервера

Во вкладке «Сервер» нажми кнопку «Остановить». При отдельном запуске через `run_server.py` нажми Enter в терминале.
